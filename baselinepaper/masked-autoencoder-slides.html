Baseline · one-class masked autoencoder

A Masked Autoencoder Baseline for Sybil Detection

Widedeep-style masked-cell reconstruction, trained on benign windows only, two encoders (TabMlp, TabResnet), at T = 64, 48 and 32 (4 seeds each)

Bibek Gupta
Department of Computer Science, Florida Polytechnic University

18 November 2026 · side experiment, not the thesis TimesNet model · task/masked_autoencoder/

This is one more baseline. It is a masked autoencoder, built after the pytorch-widedeep library. It learns only from benign windows. I trained it with two encoders, TabMlp and TabResnet, at three window sizes with four seeds each: 24 runs. The short answer: TabResnet is better than TabMlp, but both are weaker than our one-class ConvAE, and part of the score is window length.

Why try a masked autoencoder?

Hide some input cells. Ask the model to fill them in. No attack labels are needed.

Masked-cell reconstruction

Each step hides 20% of the cells. The model must guess them from the other cells. So it has to learn how the 13 features move together.

Self-supervised objective

The target is the input itself. The loss counts only the hidden cells. No label enters the loss.

One-class anomaly score

Train on benign windows only. A window that is hard to fill in is unusual. High error = alarm.

Question

Does masked reconstruction find GridSybil better than plain reconstruction (our ConvAE)?

Same data

Exactly the windows of the one-class ConvAE cells at T = 64, 48, 32.

Source of the method

pytorch-widedeep self-supervised pre-training (encoder-decoder, TabNet style).

Idea from TabNet's self-supervised pre-training as implemented in pytorch-widedeep: https://pytorch-widedeep.readthedocs.io/en/latest/examples/15_Self_Supervised_Pretraning_pt1.html

A plain autoencoder can learn to copy its input. A masked one cannot copy hidden cells. It must use the relations between features. The hope is that these relations are what a fake vehicle breaks. We train on benign windows only, so the score is how badly the model fills in a window.

The widedeep method: hide 20% of cells, rebuild them

loss = mean over rows i of
  Σj Mij (x̂ij − xij)² / varj  /  Σj Mij
varj = batch variance of column j
  • Hidden cells are set to 0 (mask is drawn on the CPU per cell).
  • Eval mode: mask of ones, nothing hidden.
  • Decoder = encoder widths reversed.

Sources: widedeep docs example 15 (Self-Supervised Pre-Training pt 1); widedeep 1.7.0 source, read only: _random_obfuscator.py, encoder_decoder_model.py L60–70, losses.py EncoderDecoderLoss, encoder_decoder_trainer.py (masked_prob 0.2, batch 32).

This is the library method. A mask hides each cell with probability 0.2. An MLP encoder and a mirrored decoder rebuild the row. The loss looks only at hidden cells, and each column is divided by its batch variance. One surprise in the source: for TabMlp the encoder receives the clean input, not the masked one. I come back to this on the deviations slide.

How we adapted it to message windows

A window is a small table: T messages × 13 features, plus a row mask for padding.

Input

896 / 672 / 448 input columns at T = 64 / 48 / 32.

Reconstruction

13 T outputs; padding cells are zero and never scored.

Training mask

A new random 20% of real cells every step (seeded). Same for both encoders.

Source: task/masked_autoencoder/model.py (MaskedTabularAutoencoder, RandomObfuscator, EncoderDecoderLoss) and config.py.

Widedeep works on tables. Our window is a table too: T rows and 13 features. We flatten it and add the row mask as extra columns, like the mask channel of the ConvAE. Only real cells can be hidden. Padding is never hidden, never in the loss and never in the score.

Three window scores, all on real cells only

The real partition uses a fixed seed (20261117), the same for every window, run and seed.

masked_recon (main score)

5 fixed masks split the cells into 5 groups of 20%. Each real cell is hidden once. Score = mean squared error of cells rebuilt while hidden.

full_recon

Nothing hidden (widedeep eval mode). Mean squared error over real cells.

mahalanobis

Distance of z (clean input) to a Gaussian fitted on benign train z.

Thresholds: benign val p95 / p99 per score. Scores of val and every test split saved to scores/<split>.npz before any label read. Source: scoring.py.

The main score uses five fixed masks. Together they cover every cell once, so each real cell is rebuilt while hidden, like in training. The score does not depend on chance. I also report plain reconstruction and a Mahalanobis distance in the latent space.

Findings

  1. Masked reconstruction does not beat plain reconstruction. GridSybil AUROC TabMlp 0.531 / 0.607 / 0.657, TabResnet 0.595 / 0.650 / 0.696 vs ConvAE 0.657 / 0.682 / 0.734 (T64 / T48 / T32).
  2. The TabResnet encoder helps at every T (+0.064 / +0.043 / +0.040; length-matched 0.578 / 0.640 / 0.678), but does not close the gap.
  3. The masked score is partly a length score: benign short vs long AUROC ≈ 0.688–0.712 (TabMlp), 0.630–0.659 (TabResnet).
  4. DataReplay 0.693 / 0.695 pooled is length, not detection: 0.490 / 0.559 length-matched (TabMlp / TabResnet), and length alone gives 0.952.
  5. Mahalanobis on z is below chance on GridSybil for both encoders (TabResnet DoSRandom 0.63 ± 0.16, unstable).
  6. Results are stable: sd ≤ 0.008 for masked_recon over 4 seeds.

One-class side experiment; all numbers from the 24 run folders (12 TabMlp + 12 TabResnet), reported as produced (RULE 1).

Six points. The masked autoencoder is weaker than our ConvAE. A stronger encoder, TabResnet, helps a little but not enough. Its main score mixes in window length. The good-looking DataReplay number disappears when we match lengths. Mahalanobis does not work here. And the seeds agree, so this is not noise.

Caveats

Two tabular encoders only

TabMlp and TabResnet (128,224 / 100,576 / 72,928 params). Both flatten the window; no convolutional or attention encoder with the masked loss.

Mac only

All 24 runs on MPS, git cff8c53 (TabMlp) / 4250b0e (TabResnet), dirty tree (git_dirty = True); no EC2 repeat.

Not literal widedeep

Our encoder sees the masked input (deviation 1). widedeep 1.7.0's own TabMlp / TabResnet path was not run.

Mahalanobis below chance

0.360–0.424 on GridSybil (both encoders); the least stable score over seeds.

DoS ≥ 4 rows = 1.000

Rests on only 523 / 524 attack windows (DoSRandom / DoSDisruptive).

Test sets differ by T

T = 32: 750 test vehicles, benign from 8 folders. T = 48 / 64: 574 vehicles, GridSybil is the majority. Compare columns with care.

Also: one-class means labels chose the benign training windows; ConvAE T32 seed 0 is a rounded value; TimesNet comparison is one seed.

Some limits. Only two tabular encoder types. Only the Mac. We changed one key detail of widedeep on purpose. Mahalanobis fails. The perfect DoS numbers on long windows rest on about five hundred windows. And the T = 32 test set is not the same as at T = 48 and 64.
