Input

One window is a 64 × 13 table: 64 messages (rows) with 13 numbers each (columns), plus a mask that marks which rows are real.

x: 64 × 13 + mask: 64

Each row is one message. Messages arrive once per second. Values are already z-scored (mean 0, std 1).

Our worked window has 28 real messages. Rows 29–64 are padding: every value is 0. The mask is 64 numbers: 28 ones, then 36 zeros.
A batch just adds B in front: B × 64 × 13 and B × 64. Here we follow one window (B = 1).

Embedding

Each 13-number row becomes a 128-number row, so the window goes from 64 × 13 to 64 × 128.

64 × 13 → 64 × 128 → 64 × 128 → X⁽⁰⁾: 64 × 128

Token embedding, then add position, then multiply by the mask.

Token embedding (Conv1d, kernel 3)

For each row t, look at the row before, the row itself and the row after. Rows outside 1…64 count as 0. There is no bias.

e_t = W₋₁ · x_{t−1} + W₀ · x_t + W₊₁ · x_{t+1}
each W128 × 13
each x13 × 1
each e_t128 × 1
all 64 rows stacked64 × 128
weights 128 × 13 × 3 = 4,992

Positional embedding

A fixed sine/cosine table tells the model where each row sits. It is added, not learned. There is no time of day.

E = TokenEmbedding(x) + PE
PE (fixed table)64 × 128
E64 × 128
positional table: 0 parameters

Apply the mask

X⁽⁰⁾ = E × mask
mask, one value per row64
X⁽⁰⁾64 × 128
The kernel and the position table put non-zero values into the 36 padding rows. Multiplying by the mask sets those rows back to 0. The 28 real rows keep their values.

Inside one TimesBlock

A TimesBlock takes a 64 × 128 matrix, finds repeating periods, folds time into a 2-D grid, convolves it, and gives back 64 × 128 again.

64 × 128→128 × 5 × 14→64 × 5 × 14→128 × 5 × 14→64 × 128

The flow shows one period (p = 14). The block does this for 3 periods, then mixes them. There are 4 blocks, one after another.

Find periods

Run an FFT along time over the 28 real rows only. Padding is left out.

real rows of X28 × 128
FFT along time: 15 frequencies (0…14)15 × 128
average |amplitude| over 128 channels15
skip f = 0 and f = 1, keep top 3 → f = 2, 4, 5
p = 28 // f → 14, 7, 5 (amplitudes ≈ 2.02, 1.56, 1.42)

Fold

Pad the 64 rows with zeros up to a multiple of p. Reshape into cycles × positions.

2-D convolution (Inception)

Inception = three Conv2d in parallel (1×1, 3×3, 5×5, "same" padding). Their outputs are averaged, so the grid size does not change.

Inception(128 → 64) → GELU → Inception(64 → 128)
input grid (p = 14)128 × 5 × 14
after first Inception + GELU64 × 5 × 14
after second Inception128 × 5 × 14

one block = 574,016

Unfold and mix

128 × 5 × 14→70 × 128→64 × 128

Unfold back to rows and cut the extra rows. Do the same for p = 7 and p = 5. Now there are three 64 × 128 results.

w = softmax(2.02, 1.56, 1.42) ≈ 0.46, 0.29, 0.25
Y = 0.46 · Y₁₄ + 0.29 · Y₇ + 0.25 · Y₅
weighted sum64 × 128

Residual + LayerNorm

X⁽ⁿᵉʷ⁾ = LayerNorm(Y + X) × mask
add block input X64 × 128
LayerNorm over the 128 numbers of each row64 × 128
× mask after the residual and again after LayerNorm: the 36 padding rows go back to 0.
LayerNorm 2 × 128 = 256 (one LayerNorm, shared by all 4 blocks)
Output is 64 × 128, the same size as the input, so blocks stack. The periods can change from block to block (this window: 14, 7, 5 in block 1; 14, 7, 9 in blocks 2–4). A window with fewer than 4 real rows uses period 1. d_ff = 64 is a bottleneck that keeps the block small.

Output: H and z

After 4 TimesBlocks the encoder gives one vector per message (H) and one vector per window (z).

64 × 128→ H 64 × 128→ 28 × 128→ z 128

H is 64 × 128: one 128-vector for each message. The 36 padding rows of H are 0.

z is the masked mean of H. Only the 28 real rows count.

z = (sum of the 28 real rows of H) ÷ 28
real rows of H28 × 128
sum over rows1 × 128
÷ 28 → z128
Why not divide by 64? The 36 zero rows would shrink z and reveal the window length. Example: real values [2, 4, 6] plus 2 padding zeros. Plain mean = 12 ÷ 5 = 2.4. Masked mean = 12 ÷ 3 = 4.0.
encoder: embedding 4,992 + 4 × 574,016 + LayerNorm 256 = 2,301,312
A batch just adds B in front: x B × 64 × 13 → H B × 64 × 128 → z B × 128 (B = 256 in the notebook).
