Commands

Run from the repo root (npm only runs the Python tools).

npm run setup · setup:cpuone-command Docker setup (GPU / CPU)
npm run pipeline:prepare · pipeline:encoder-inputbuild the prepared data and the encoder input
npm run train:check · train:smoke · train:fullchecks · short run · full pretraining run
npm run train:resume -- <run_dir> · train:runsresume a run · list runs
npm test · npm run checkpytest · format check + tests
npm run data:download · model:upload · model:listprivate Hugging Face repos
npm run sim:data · npm run simsimulator sample · simulator dev server

Raw data in data/ is protected (read-only). No pretraining result exists yet; the v1 pilot numbers in models/ are invalid as evidence.
