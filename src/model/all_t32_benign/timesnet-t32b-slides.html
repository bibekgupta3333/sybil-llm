Goal: does self-supervised pretraining help a one-class detector?

Train on benign only

TimesNet learns from 502,773 benign windows of all 8 scenario folders. It never sees an attack window.

Score with a frozen encoder

Reconstruction error, Mahalanobis distance and kNN distance on the window vector z.

Compare fairly

Same split and same test windows as the one-class ConvAutoencoder baseline. Also an untrained encoder and a length-only score.

Question for today

Is the pretrained z better than an untrained z and better than window length?

If yes, pretraining adds something. If no, the score only follows a shortcut.

Data: src/data/encoder_input/all/T32_benign. Run: src/runs/pretraining/all/T32_benign/model-t32b-seed0.

The aim is simple. Train TimesNet with self-supervised losses on benign data only. Then check if the learned window vector separates attacks from benign. The two controls are important: an untrained encoder and the window length alone.

TimesNet finds the main periods of each window with an FFT, folds the sequence into a 2-D grid and applies 2-D convolutions. Four blocks, width 128. The output is H, one vector per message, and z, the masked average of H. After pretraining only the encoder is kept. Padding does not change z.

Three self-supervised objectives, one joint loss

Masked reconstruction

Hide 25% of the real rows (or one block of 20–30%). The MLP on H predicts the 13 features. Loss = MSE on hidden rows.

Physics heads P1–P3

We inject one violation into half of the windows (≥ 4 rows): P1 position jump 50–150 m, P2 speed × 2–3 or × 0.2–0.5, P3 turn of 90–180°. Each head detects its type.

Contrastive NT-Xent

Two physically consistent views of a window (shift 3–5 m, time stretch, crop) must be close in z. Temperature 0.1; same-broadcast pairs are masked.

L = 1·Lrecon/srecon + 0.3·Lnce/snce + 0.3·(LP1/sP1 + LP2/sP2 + LP3/sP3)

Each scale s is the mean of that loss over its first 200 updates, then frozen: srecon 0.573, snce 1.763, sP1 0.528, sP2 0.454, sP3 0.456. Windows with fewer than 4 rows give only the reconstruction loss.

Settings from config.json; scales from history.jsonl; formula in timesnet/losses.py.

Three tasks. Reconstruct hidden rows. Detect a violation that we inject ourselves; these are not real attacks. And make two harmless views of the same window close together. Each loss is divided by its early mean, so the losses have similar size, then weighted: 1 for reconstruction and 0.3 for the others.

Why

These attacks change pseudonym every 1–2 messages (F11). Almost every window is very short, so length alone scores 0.95–0.97.

So

The untrained encoder ties with or beats the pretrained one. These splits give no evidence either way.

Caveats and next steps

Caveats

One seed

No spread yet. The ConvAE has 4 seeds.

Injection too easy

P1–P3 AUROC ≥ 0.9988; little signal late in training.

Random-init already strong

Untrained kNN gives 0.839 on GridSybil. Always report this control.

Mahalanobis condition number 1.83e+15

LayerNorm gives z one null direction. Shrinkage 0.01 handles it (ANALYSIS.md).

Data limits

F14: GridSybil_0709 near-copies may cross the split (not measured). Labels select the benign data.

Next steps
