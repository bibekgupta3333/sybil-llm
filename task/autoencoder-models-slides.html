What worked

  • Labels: the same small encoder reaches 0.928 / 0.929 / 0.926 (T64 / T48 / T32).
  • Benign-only training: GridSybil 0.655 (T64) and 0.736 (T32); 0.778 on ≥ 4-row windows.
  • Short windows with labels: 1–3 rows still 0.917 / 0.915.
  • Per-feature error: GridSybil log Δτ 3.563 vs benign 0.130 (study 5).

Test window AUROC, attack = positive; per-feature error = masked MSE · one seed except study 1

Labels work at every T. Without labels, only benign-only training helps, and it helps most on longer windows.
Overview›1›2›3›4›5›6›Findings›Comparison›TimesNet

What did not work

  • Attacks as normal: 0.484 twice (studies 2, 3).
  • Latent distance: below chance, 0.319 and 0.337.
  • DataReplay: 0.391, while length alone gets 0.952.
  • DoSDisruptive: 0.611 vs length 0.967.
  • One-class vs statistics: 0.655 vs 0.855 (53 statistics + logistic regression).

Reconstruction error inside the supervised models: 0.478 (study 4), 0.598 (study 6)

If attacks are in the normal data, the model learns them as normal. Window-level scores fail on DataReplay and DoS, where length wins.
