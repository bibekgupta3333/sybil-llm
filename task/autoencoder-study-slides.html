Question and setup

Can a model trained without labels flag GridSybil windows because they are hard to rebuild?
  • Train an autoencoder to compress a window into 16 numbers (z) and rebuild it.
  • Every train window counts as normal: benign and GridSybil alike. No labels in training, model selection or thresholds.
  • Detect by "hard to rebuild" (reconstruction error) or "far from the usual z" (Mahalanobis, Study B).
  • Labels are read only after every test window has its score.

Positive class

GridSybil (attack code 16). Negative: benign.

Same model in both studies

Scoring: two scores, two levels, one threshold rule

Reconstruction error

Masked MSE of one window over its real rows. High = hard to rebuild.

Mahalanobis on z (Study B)

Distance of z from a Gaussian fitted on train z (16 × 16 covariance, condition number 38.6, no shrinkage).

Per window vs per track (Study B)

A track = one link (receiver, pseudonym, sender). Track score = max or mean of its windows. Test: 42,653 windows in 35,957 tracks, no track with mixed labels.

Threshold = val p95

95th percentile of the unlabeled val scores; above it = alarm. Reconstruction, window level: θ = 0.372 (A), 0.401 (B). Expect ≈ 5% benign false alarms.

Order of work: score every test window first, then read the labels.

Why it fails

  • GridSybil is ~64% of train, so the model learns it as normal.
  • Ghost windows are rebuilt as well as real cars: better on claimed velocity, worse on range and claimed position. Overall the window error ends up about the same.
  • Mahalanobis is below chance: GridSybil z sits at the centre of the fitted Gaussian, so benign windows look like the outliers.
  • Overlap changed nothing: 0.484 in both (different cut and train / val vehicles, so context only).

Lessons and next step

What we learned

  • Good reconstruction ≠ detection. Low error on everything means nothing stands out.
  • "Normal" must mean benign; mixing attacks into the normal set teaches the model to accept them.
  • The pipeline held: vehicle splits, labels read last, val thresholds (val p95 gave benign FPR 0.049 / 0.050, as intended).

Next

  • Train on benign only (one-class), same data and splits.
  • Then scores on z and on co-movement between pseudonyms (ghosts of one attacker move together).
  • Keep val for thresholds; run more seeds and report spread.

Context only: an earlier benign-only run at T = 64 reached AUROC 0.655 (different T and training set, not a fair comparison).
